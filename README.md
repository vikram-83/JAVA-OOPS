## 💻 Example

```java
class Student {
    String name;
    int age;

    void display() {
        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
    }
}

public class Main {
    public static void main(String[] args) {
        Student s1 = new Student();

        s1.name = "Vikram";
        s1.age = 22;

        s1.display();
    }
}
```

### Output

```text
Name: Vikram
Age: 22
```
